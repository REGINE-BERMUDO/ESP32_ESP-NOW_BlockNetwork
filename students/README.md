# Student directory

Use this page to find a student's results. Personal folders stay at the top
level because that is where the activity requires them.

The owner adds a directory entry after merging each student's first pull
request. Students submit only their own folder; they do not need to edit
this page. A link here means a folder exists, not that attendance or results
have been approved by the instructor.

To add your results, follow [the submission guide](../CONTRIBUTING.md).
Read [the block-session instructions](../docs/block-session.md) before
collecting evidence.
