# Student directory

Student results will be linked here after their pull requests are merged.
No submissions are listed yet. The repository owner submits their personal
evidence through the same process as everyone else.

| Student folder | GitHub account | Results |
| :--- | :--- | :--- |

The owner adds an entry after merging each student's first results pull
request. Students submit only their own folder and do not need to edit this
page. A directory entry records the files that are present; it is not an
attendance approval or grade.

Personal folders stay at the top level, as required by the activity.
Follow [the submission guide](../CONTRIBUTING.md) to add your own results,
and read [the block-session instructions](../docs/block-session.md) before
collecting evidence.
